# yukti.integrations.opentelemetry — Opentelemetry

**Status:** scaffolded, not yet implemented (v0.0.1).

This is a planned core integration. The implementation lives in this
directory and will subclass `yukti.integrations.base.Integration`,
declare its supported `Capability` values, and ship as a core extra
under `pip install yukti[opentelemetry]`.

See `src/yukti/integrations/webhook/` for the reference implementation
pattern.
